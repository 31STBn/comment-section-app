# Live Comment Section System 🎙️💬

A real-time, bilingual (Bangla & English) interactive stage comment system. Audiences scan a QR code on the stage screen with their mobile devices to submit their names and comments, which appear live beside the QR code in real-time.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Server Actions)
- **Styling & UI:** Tailwind CSS, Lucide Icons, Canvas Confetti
- **QR Code Engine:** `qrcode.react` with custom frame and color designer
- **Database & Realtime Sync:** Supabase Realtime
- **Deployment:** Vercel
